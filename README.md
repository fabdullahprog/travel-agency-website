
# 🌍 Travel Agency Website

A responsive **Travel Agency Website** built using **HTML5** and **CSS3**. This project showcases popular travel destinations, tour packages, an online booking form, and a contact page with a clean and modern user interface.

---

## 📌 Project Overview

This website is designed for a travel agency to help users explore destinations, view tour packages, and submit booking requests through an easy-to-use interface.

---

## ✨ Features

- 🏠 Home Page
- 🌍 Popular Destinations
- 🎒 Tour Packages
- 📝 Online Booking Form
- 📞 Contact Page
- 📱 Fully Responsive Design
- 🎥 Images & Videos
- 📍 Google Map Integration

---

## 🛠️ Technologies Used

- HTML5
- CSS3
